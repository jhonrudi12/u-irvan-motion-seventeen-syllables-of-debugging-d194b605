Seventeen Syllables of Debugging: one haiku about debugging, three lines in the 5-7-5 shape. A breakpoint that keeps waiting, a thousand logs that say nothing — and the turn: the semicolon.

## Run it

```sh
python3 main.py
```

It writes the haiku to `/output/entry.txt` (plain text, 71 characters, pure Python standard library, deterministic — same bytes every run).
